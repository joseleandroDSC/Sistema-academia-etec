# Sistema-academia-etec

#Descrição
Sistema simples de cadastro de alunos desenvolvido em C# utilizando Programação Orientada a Objetos.

#Funcionalidades
- Cadastrar alunos
- Listar alunos
- Menu interativo no console

#Tecnologias
- C#
- .NET

#Como executar
1. Abrir o projeto no Visual Studio
2. Executar o arquivo Program.cs
